# Mini Support Ticket Tracker

Small full-stack application for managing support tickets.

- **Backend** — Node.js / Express / TypeScript, SQLite via `better-sqlite3`
- **Frontend** — React 18 + Vite + TypeScript
- **Infra** — multi-stage Docker images (API and static frontend), `docker compose`

> **Status:** scaffolding. Run instructions, API summary and assumptions are filled in
> as the features land — see `docs/` for the current architecture notes.
